# Audit Prompts & Instructions

> **Authority Level:** Procedural Instructions (`audit-prompts/`)  
> Documents in this directory are standardized prompts and guidelines for executing audits.

## Purpose

Audit prompts define:
> *"How should an AI coding assistant or engineer execute a specific type of audit?"*

These are **not** audit findings or results; they are reusable instructions and inspection criteria.

*No active prompt templates currently in use. Prompts are maintained in the permanent audit playbooks under [`../audits/`](../audits/README.md) and historical prompts are preserved in [`../archive/audit-prompts/`](../archive/audit-prompts/).*
